# Ramachandran V - Java Developer Portfolio

An interactive, high-performance developer portfolio website for **Ramachandran V**, Senior Java Developer with 5+ years of experience specializing in Spring Boot, RESTful Microservices, AWS Cloud Infrastructure, Genesys Integration, and High-Throughput ETL Pipelines.

## 🚀 Features

- **3D WebGL Background**: Interactive 3D visual particle background using Three.js.
- **Modern Cyber Theme**: Dark mode aesthetic with glassmorphism, dynamic cursor effects, and smooth scroll animations.
- **Interactive Portfolio**: Showcases work experience, technical skills, projects, certifications, and contact options.
- **Responsive Layout**: Fully responsive across desktop, tablet, and mobile devices.

## 🛠️ Built With

- **HTML5 & CSS3**: Semantic markups, CSS Grid/Flexbox, dynamic animations, and custom styling.
- **JavaScript (ES6+)**: Interactive logic, custom cursor, filtering, and scroll interactions.
- **Three.js**: Real-time WebGL rendering and particle systems.
- **FontAwesome & Devicon**: High quality tech icons and brand logos.

## 📂 Project Structure

```
├── index.html         # Main portfolio HTML page
├── styles.css         # Custom styling and theme variables
├── script.js          # Core application logic & UI handlers
├── 3d_background.js   # Three.js 3D WebGL background animation
└── assets/            # Images, profile pictures, and project visual assets
```

## 💻 Getting Started

To view the portfolio locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/Barath025/Ram-portfolio.git
   ```
2. Open `index.html` in your favorite web browser or use VS Code Live Server.
